ResumeAI Pro

ResumeAI Pro is a resume screening and ATS analysis platform designed to process candidate resumes, evaluate keyword alignment, predict domain role suitability using supervised machine learning, and compute multi-factor ATS compliance metrics.

1. Project Overview

ResumeAI Pro automates document ingestion, structural parsing, and candidate qualification scoring. By leveraging Natural Language Processing (NLP) techniques and term frequency-inverse document frequency (TF-IDF) feature matrix representations, the application evaluates candidate resumes against industry skill taxonomies and job description requirements to provide actionable diagnostic feedback.

2. Core Features
Resume Parsing Extracts plain text and contact entities (Name, Email, Phone, LinkedIn, GitHub) from PDF and DOCX documents.
ATS Score Calculation Computes a multi-factor compliance score out of 100 based on contact integrity, skills density, projects, education, and formatting.
Resume Classification Classifies resumes into predicted job domain categories using supervised machine learning classifiers.
Skill Extraction Identifies technical languages, frameworks, databases, and DevOps tools using boundary regex matching.
Keyword Analysis Calculates top term frequencies and identifies keyword density distributions across the document.
Job Description Matching Compares candidate skill profiles directly against target Job Descriptions to surface matched and missing keywords.
Interactive Dashboard Visualizes ATS factor scores, section presence, and keyword distributions via Chart.js canvases.
Download Report Generates downloadable plain text ATS diagnostic audit reports for candidate reference.
3. NLP Pipeline
  1. Resume Upload: File stream ingestion supporting PDF and DOCX formats.
  2. Text Extraction: Text stream extraction using PyPDF / python-docx parsers.
  3. Text Cleaning: Removal of special characters, non-ASCII symbols, and URL normalization.
  4. Tokenization: Word tokenization and case normalization.
  5. Stopword Removal: Filtering standard English stop words using NLTK corpora.
  6. Lemmatization: Root form normalization using spaCy lemmatization.
  7. Feature Extraction: Vectorization of unigrams and bigrams.
  8. TF-IDF Vectorization: Term Frequency-Inverse Document Frequency matrix transformation.
  9. Machine Learning Prediction: Supervised classification to infer domain role suitability.
  10. ATS Calculation: Multi-factor weighted score compilation out of 100.
  11. Final Report: Rendering of interactive dashboard metrics and text report generation.
